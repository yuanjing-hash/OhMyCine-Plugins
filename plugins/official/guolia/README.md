# 挂了.com BT 资源站插件

首版只访问用户在连接配置中选择的一个镜像入口，支持种子搜索、详情页磁力解析、账号密码登录、Cookie 粘贴和站点验证码挑战。

入口不会自动跨域切换。切换镜像会清除旧登录状态和短期搜索结果，用户必须在新入口重新登录。站点返回浏览器安全验证或限流时，插件只上报状态，不会绕过验证或无限重试。

0.1.4 的登录检测读取当前镜像返回的账号状态，不再用搜索结果格式判断登录。手动完成网页登录后，由 Server 在同一浏览器会话内确认并加密保存 Cookie；网页仅加载成功不等于登录成功，未知页面仍会报告无法确认。登录检测与搜索解析分别验收，尚不能据此宣称真实账号搜索、磁力解析已通过端到端测试。
