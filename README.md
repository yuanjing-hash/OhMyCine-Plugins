# OhMyCine Plugins

OhMyCine 官方插件 Registry 与 Release 仓库。一个仓库可以发布多个插件，OhMyCine Server 会固定默认分支提交并校验 Registry、Manifest、包摘要、权限和兼容范围后再允许安装。

在 Server 的“插件 → 仓库设置”中添加：

```text
https://github.com/yuanjing-hash/OhMyCine-Plugins
```

## 当前插件

- `org.ohmycine.bilibili`：Bilibili 在线媒体库 Beta。

插件 SDK、协议和源码位于 [OhMyCine](https://github.com/yuanjing-hash/OhMyCine) 主仓库。
